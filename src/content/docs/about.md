# 关于 OpenGood

OpenGood，取 **Open（开放）+ Good（向善）** 之意。这是一个个人小站：用开放的方式记录所学所作，用向善的心态对待技术。

## 两条主线

- **开放**：开源、共享、透明。代码与文字尽量公开，欢迎讨论与复用。
- **向善**：科技向善。关注技术对人的影响，做有益、克制、可信赖的东西。
