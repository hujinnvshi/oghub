# 第一篇文章

欢迎来到我的站点！这是一篇示例文章，用来演示内容结构。

## 你能做什么

- 用 Markdown 写正文
- 在 `src/content/docs/articles/` 下新增 `.md` 文件即可发布新文章
- 文件头的 `title` / `description` 会出现在侧边栏和搜索结果里

## 代码示例

```js
function greet(name) {
  return `Hello, ${name}!`;
}
```
